Keera Chat

Privater KI-Chat, unter deinen Regeln

Keera Chat ist der KI-Assistent im Browser für alle in deinem Unternehmen. Jede Nachricht läuft durch Keera Gateway und hält sich an dieselben Regeln wie jede andere Anfrage.

Kostenlos starten Keera Chat öffnen ➔

Wie Keera Chat funktioniert

Du meldest dich mit deinem Keera-Konto an und chattest los. Du musst nichts installieren und keinen API-Key kopieren. Verbrauch und Kosten stehen im Gateway unter deinem Namen.

Was Keera Chat kann

Nur erlaubte Modelle

Du siehst nur die Modelle, die deine Keys erlauben.

Budget im Blick

Du siehst, wie viel von deinem Budget schon verbraucht ist.

Chats bleiben bei dir

Deine Chats liegen nur in deinem Browser. Das Audit-Log hält die Anfrage fest, nie den Inhalt.

Wie gewohnt

Markdown, Tabellen, Code und Bilder, auch auf dem Handy.

So bekommt dein Team Keera Chat

In der Swiss Cloud chattest du auf chat.keera.ch, mit deinem Gateway-Konto. Betreibst du Keera Gateway selbst, stellst du Keera Chat daneben. Den Quellcode kannst du auf GitHub lesen (Keera Community Licence).

Wer chatten soll, braucht einen Key, der ein Chat-Modell erlaubt. Den vergibt die Administration im Gateway.

Wie du Keera Chat benutzt und betreibst, steht in der Dokumentation.

Häufige Fragen zu Keera Chat

Das fragen uns Teams, bevor sie Keera Chat für alle freigeben.

Speichert Keera Chat meine Chats?

Nur in deinem Browser. Weder der Prompt noch die Antwort wird auf einem Server gespeichert oder für Training verwendet. Keera Gateway hält nur die Anfrage fest: wer, wann, welches Modell, wie viele Tokens, welcher Entscheid - im Audit-Log deines Unternehmens.

Welche Modelle kann ich in Keera Chat nutzen?

Die, die dein Key erlaubt. Die Administration wählt sie in Keera Gateway aus, pro Team und Datenklasse, aus den Modellen im Modellkatalog.

Was kostet Keera Chat?

Keera Chat gehört zu Keera Gateway und kostet nichts extra. Du zahlst die Modellnutzung wie bei jeder anderen Anfrage durch das Gateway, und sie zählt gegen dein Budget.
