Keera Gateway comes in five plans. Three run on a shared instance in the Swiss cloud and differ only in how many tokens pass through a day. Two give you a gateway of your own.

Keera Gateway in the Swiss cloud

Free, Pro and Max run on a shared instance at a Swiss cloud provider and all do the same things. The plan only sets how many input tokens pass through each day. The price is per organisation, not per user.
