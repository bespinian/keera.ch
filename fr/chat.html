Keera Chat

Un chat IA privé, selon vos règles

Keera Chat est l'assistant IA dans le navigateur pour toute votre entreprise. Chaque message passe par Keera Gateway et suit les mêmes règles que toute autre requête.

Commencer gratuitement Ouvrir Keera Chat ➔

Comment fonctionne Keera Chat

Connectez-vous avec votre compte Keera et commencez à discuter. Rien à installer, aucune clé API à copier. La consommation et les coûts apparaissent dans la passerelle à votre nom.

Ce que fait Keera Chat

Seulement les modèles autorisés

Vous ne voyez que les modèles que vos clés autorisent.

Le budget en vue

Vous voyez quelle part de votre budget est déjà dépensée.

Vos conversations restent chez vous

Vos conversations restent dans votre navigateur. Le journal d'audit enregistre la requête, jamais son contenu.

Comme d'habitude

Markdown, tableaux, code et images, aussi sur mobile.

Comment votre équipe obtient Keera Chat

Sur Swiss Cloud, vous discutez sur chat.keera.ch avec votre compte de la passerelle. Si vous exploitez Keera Gateway vous-même, vous installez Keera Chat à côté. Son code source est lisible sur GitHub (Keera Community Licence).

Pour discuter, une personne a besoin d'une clé qui autorise un modèle de chat. L'administration l'émet dans la passerelle.

La documentation explique comment utiliser et exploiter Keera Chat.

Questions fréquentes sur Keera Chat

Ce que les équipes nous demandent avant d'ouvrir Keera Chat à tout le monde.

Keera Chat conserve-t-il mes conversations ?

Seulement dans votre navigateur. Ni le prompt ni la réponse ne sont conservés sur un serveur ou utilisés pour l'entraînement. Keera Gateway ne conserve que la requête : qui, quand, quel modèle, combien de tokens, quelle décision - dans le journal d'audit de votre entreprise.

Quels modèles puis-je utiliser dans Keera Chat ?

Ceux que votre clé autorise. L'administration les choisit dans Keera Gateway, par équipe et par classe de données, parmi les modèles du catalogue.

Combien coûte Keera Chat ?

Keera Chat fait partie de Keera Gateway et ne coûte rien de plus. Vous payez l'utilisation des modèles, comme pour toute autre requête via la passerelle, et elle compte dans votre budget.
