Tarifs · Keera Gateway

Commencer gratuitement, grandir avec le volume

Keera Gateway existe en cinq formules. Trois tournent sur une instance partagée dans le cloud suisse et ne diffèrent que par le nombre de tokens qui passent chaque jour. Deux vous donnent une passerelle rien qu'à vous.

Commencer gratuitement Voir Keera Gateway ➔

Keera Gateway dans le cloud suisse

Gratuit, Pro et Max tournent sur une instance partagée chez un fournisseur cloud suisse et font tous la même chose. La formule fixe seulement le nombre de tokens d'entrée qui passent chaque jour. Le prix s'entend par organisation, pas par utilisateur.
