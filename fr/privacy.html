Protection des données

Politique de confidentialité

Quelles données personnelles nous traitons sur keera.ch et dans Keera Gateway, dans quel but, et qui les reçoit.

Version du 13 octobre 2026

Qui est responsable

Le responsable du traitement est bespinian GmbH, Sonnenweg 9, 3073 Gümligen, Suisse. Pour toute question sur vos données, écrivez à info@bespinian.io.

Nous ne vendons aucune donnée personnelle.

Lorsque vous visitez ce site

keera.ch est hébergé sur GitHub Pages. Lorsqu'une page est demandée, GitHub traite des données techniques comme l'adresse IP, l'heure, la page et le navigateur, pour la livrer et la protéger. Les polices et les images viennent de keera.ch même, pas de tiers.

Formulaire de contact et e-mail

Ce que vous saisissez dans le formulaire - nom, e-mail, entreprise, intérêt, message et la langue de la page - nous parvient par e-mail via Formspree. Nous l'utilisons uniquement pour vous répondre et vous faire une offre.

Nous le conservons tant que votre demande est ouverte ou qu'une relation commerciale en découle. Il en va de même pour les e-mails que vous nous envoyez.

Dans Keera Gateway

Pour votre compte, nous recevons votre nom et votre adresse e-mail du service avec lequel vous vous connectez. Un cookie vous garde connecté. Pour chaque requête, nous enregistrons qui l'a envoyée, quand et à quel modèle, combien de tokens elle a utilisés, ce qu'elle a coûté et ce que la passerelle a décidé - dans le journal de votre organisation, que ses administrateurs consultent.

Nous ne conservons ni les prompts ni les réponses. Nous les transmettons au fournisseur de modèles que votre organisation a choisi. L'instance partagée tourne chez Nine en Suisse. Votre organisation est responsable des données de ses requêtes ; nous les traitons pour son compte.

Paiement

Vous payez le crédit via PostFinance Checkout. Vous saisissez votre carte sur la page de paiement de PostFinance ; nous ne la voyons jamais. Nous recevons la transaction, le montant et, si vous enregistrez la carte, un jeton qui permet de la débiter à nouveau.

Nous conservons paiements et factures pendant dix ans, comme le droit suisse l'exige pour les pièces comptables.

Vos droits

Vous pouvez demander quelles données nous détenons sur vous, les faire rectifier ou effacer, vous opposer à leur traitement et les recevoir dans un format courant. Écrivez à info@bespinian.io.

Si notre manière de traiter les données change, nous mettons cette page à jour. La version publiée ici fait foi.
